# 🎯 Pick a Winner | አሸናፊ ይምረጡ

A bilingual (English/Amharic) winner picker wheel application.

## ✨ Features
- 🎡 360° spinning wheel
- 👥 Add participants (single or bulk)
- 🏆 Winner tracking (1, 2, 3...)
- 📄 Export to PDF (winner_list.pdf)
- 💾 Local storage persistence
- 📱 Mobile responsive
- 🌍 English/Amharic language support
- 🎉 Confetti celebration

## 🚀 Live Demo
[Try Pick a Winner](https://Haile-Kefle-cs.github.io/pick-a-winner/)

## 🎯 How to Use
1. Add participant names
2. Click "PICK A WINNER"
3. Watch the wheel spin
4. Celebrate the winner!

## 🔤 Language Support
- English: Use comma (,) separator
- Amharic: Use Amharic comma (፣) separator

## 🛠️ Technologies
- HTML5
- CSS3
- JavaScript
- jsPDF for PDF export
- html2canvas for Amharic PDF support
- LocalStorage for data persistence
